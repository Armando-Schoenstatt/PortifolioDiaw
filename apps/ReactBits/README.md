# Efeito ReactBits

Esta aplicação React contém somente o efeito Fumaça (`SplashCursor`). Ele é usado como cursor global do portfólio, sem seletor, card ou botão para ocultá-lo.

O rastro usa cinza-gelo (`#cbd5e1`) para combinar com a identidade monocromática do site. O canvas não bloqueia interações e respeita a preferência de movimento reduzido do sistema.

## Execução

Na raiz do portfólio:

```bash
npm install
npm run dev
```

O componente de cursor fica em `src/cursor.jsx`; a demonstração React desta aplicação fica em `src/App.jsx`.
